OUTILS DE BUREAU — NAVenza MAP 5.2
(Ne pas téléverser sur GitHub : ces fichiers restent sur votre ordinateur.)

navenza_qgis.py
  Dans QGIS : Extensions > Console Python > Afficher l'éditeur > Ouvrir ce fichier > Exécuter.
  Puis, dans la console :

  1) Préparer un calque de suivi exporté de QGIS (GeoJSON, EPSG:4326) :
       preparer_calque(r"C:\chemin\suivi_castors_2027.geojson",
                       {"etat": ["actif", "inactif", "démantelé"],
                        "hauteur_eau_cm": "nombre",
                        "accessible": "ouinon",
                        "remarques": "texte"})
     → les employés verront ces champs à remplir dans chaque point du calque.

  2) Fusionner les envois reçus (mettre tous les .geojson ET .kmz reçus dans un dossier,
     sous-dossiers permis) :
       fusionner_retours(r"C:\chemin\Retours terrain")
     → crée navenza_fusion.geojson (un enregistrement par point, la version la plus
       récente gagne) et le dossier photos\ ; ajoute les couches au projet QGIS.

modele_calque_suivi.geojson
  Exemple complet : champs id, nom, symbole, statut, remarque + définitions de champs.
  Valeurs de « symbole » : castor inactif, castor actif, frayère, embâcle, protection,
  artefact, point, danger, camp, ponceau, accès, note.
  Valeurs de « statut » : à faire, fait, problème.
